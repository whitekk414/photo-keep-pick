# Photo Keep Pick

把一小批连拍照片放到同一目录，在浏览器中并排看缩略图，每组手动挑选一张。程序只读原图，所有计算在本机完成。

## 运行

需要 Python 3.10 或更高版本。在项目目录执行：

```sh
python -m pip install -r requirements.txt
python app.py "相片目录" "review-output.html"
```

双击生成的 HTML。勾选照片、更改选择或清除本组选择后，点击「导出选择清单」。JSON 按组列出候选文件名和所选的 keeper，未选择时为 null。选择只保存在当前页面会话中。输出 HTML 需使用新文件名，里面嵌入了照片缩略图，分享时请留意。

扫描顶层 JPEG、PNG、WebP 和 BMP。程序比较宽高比、缩小后的色块和 64 位差异哈希，将相近的照片归入首个匹配的代表图所在组。裁剪、旋转和曝光变化可能造成漏分，近似构图也可能误分，最终选择由用户决定。建议从几十张照片开始，扫描会在内存中保存缩略图。

## 合成样例验证

运行 `python test_review.py`。测试生成两张相同图案、一张不同图案和一个损坏文件，检查分组、损坏文件处理、源文件完整性和已有输出保护。

## 从确认的保留项学习

在原图目录旁运行以下命令（把路径替换为自己的）。先在对照页导出清单，再决定是否让工具记住选择：

```sh
python habits.py summary "相片目录"
python habits.py learn "相片目录" "keepers.json"
python app.py "下次的相片目录" "下次选片.html" --personal
python habits.py clear
```

`summary` 按画幅、EXIF 拍摄小时和 35 mm 等效焦距统计当前目录，缺失字段显示为未知。统计仅打印到终端。学习选片时，工具比较同组照片的亮度、对比度和边缘强度，将最终选择的相对排名保存在用户目录下的 `.photo-keep-pick/choices.sqlite3`。同组重复导入会更新记录，空选会撤销该组记录。积累至少三组选择后，带 `--personal` 生成的新页面会在有明确偏好时标出候选，仍由你确认。选片模型目前使用这些画面特征，尚不能识别表情或视线方向。运行 `clear` 删除选片模型。

## 选片后裁剪

```sh
python crop.py --keepers keepers.json --folder "相片目录"
python crop.py "照片.jpg"
```

使用带 Tk 的 Python。也可以直接运行 `python crop.py` 打开文件选择器。选择目标比例后，拖动取景框、用滑杆放大，再导出一张全分辨率裁剪的 JPEG。上一张、下一张可以切换清单内的保留项。原图和已有文件均受保护。

勾选「记住我的裁剪习惯」后，软件只从成功导出的构图学习。默认框按画面边缘密度估算视觉中心。个性化框参照相同目标比例、视觉中心和亮度相近的其他照片，学习位置偏移和放大倍数。可随时切换默认构图。这里的视觉中心是图像特征估计，无法区分人物眼睛、看向或表情。

本地数据库 `~/.photo-keep-pick/crops.sqlite3` 保存图片摘要、画幅、场景特征、默认框、实际使用的建议框、最终框、用时和采用情况。框以原图宽高为单位归一化。每张图每种比例保留最近一次导出；取消、切图和试拖不产生记录。「查看效果」展示已记录照片的直接采用次数和平均操作时间。「清除裁剪记录」删除该数据库。裁剪学习和选片学习独立开启。
