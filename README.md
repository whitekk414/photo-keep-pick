# Photo Keep Pick

把一小批连拍照片放到同一目录，在浏览器中并排看缩略图，每组手动挑选一张。程序只读原图，所有计算在本机完成。

## 运行

需要 Python 3.10 或更高版本。在项目目录执行：

```sh
python -m pip install -r requirements.txt
python app.py "相片目录" "review-output.html"
```

双击生成的 HTML。勾选照片、更改选择或清除本组选择后，点击「导出选择清单」。JSON 按组列出候选文件名和所选的 keeper，未选择时为 null。选择只保存在当前页面会话中。输出 HTML 需使用新文件名，里面嵌入了照片缩略图，分享时请留意。

扫描顶层 JPEG、PNG、WebP 和 BMP。程序比较宽高比、缩小后的色块和 64 位差异哈希，将相近的照片归入首个匹配的代表图所在组。裁剪、旋转和曝光变化可能造成漏分，近似构图也可能误分，最终选择由用户决定。建议从几十张照片开始，扫描会在内存中保存缩略图。

## 合成样例验证

运行 `python test_review.py`。测试生成两张相同图案、一张不同图案和一个损坏文件，检查分组、损坏文件处理、源文件完整性和已有输出保护。
